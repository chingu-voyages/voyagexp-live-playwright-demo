## Overview

Hi, Chingus! 👋

It's one thing to listen to a presentation on a topic like Playwright, but
quite another to actually use it. The objective of this repo is to provide you
a sample application you can clone to explore Playwrite testing by creating
and running tests on a very simple application.

## General Instructions

1. To use this repo start by cloning it to a new repo on your local computer.
```bash
git clone https://github.com/chingu-voyages/voyagexp-live-playwright-demo
```

2. Build the application
```
npm i
```

3. Add any tests you create in the `/tests` directory. Their file names should
be suffixed with `.spec.js`

4. You can run tests with the command, `npm run test`, which is defined
in `package.json`.

5. To review the output of the tests, including any you have added, use the
command `npm run test:report`. This command is also defined in the
`package.json` file.
